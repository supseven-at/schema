# TYPO3 Extension ``schema``

The `EXT:schema` extension is used to generate structured data (JSON-LD) for search engine optimization (SEO). The generation is based on the PHP library `spatie/schema-org`.

### Installation as extension from TYPO3 Extension Repository (TER)

Using composer: `composer require supseven/schema`
